Claude Setup

Get Claude Cowork running, connect your tools, and install the Sourcing Intelligence plugin.

Order of setup

  1. Set up Claude Cowork with the Claude Cowork Starter Pack 2026.
  2. Connect the required connectors below.
  3. Install the Sourcing Intelligence plugin (plugin version 1.2.0, updated June 2026).
  4. Work from the CodePath workspace folder in Cowork. That is where .claude-memory/ and your voice profile live.
  5. Run /source-start to see the user guide and commands.

Required connectors

The plugin does not work without these. Connect each in Claude settings, then Connectors.

ConnectorWhy it is needed
Google DriveReads JDs from the Role Launches folder and saves all sourcing output to the Sourcing Strategy folder. Sign in with your CodePath Google account.
NotionQueries active roles, sourcing plans, and channel history. Authorize with the CodePath workspace.
SlackSends batch sourcing summaries when a run completes. The default channel is #[yourname]_Claude_sourcing, created automatically on first use.

Strongly recommended

  • Claude in Chrome: needed for batch sourcing via LinkedIn Recruiter, saving candidates to Gem, and pulling Greenhouse channel performance reports. Install the extension and keep a browser window open during sessions.
  • HeadHunter: the preferred batch sourcing engine, faster and more precise than LinkedIn Recruiter. Ask Mitchell Bryson to add you. Without it, the plugin falls back to LinkedIn Recruiter through Chrome.
  • Gmail: creates outreach email drafts. Without it, outreach copy is delivered as text to paste.

Configuration

  • Voice profile: for personalized outreach, a profile built from your past outreach is stored in the plugin. If you do not have one, share 3 to 5 past outreach samples with Erica.
  • Sourcing Rubrics doc: the shared rubrics checklist lives in the Role Launches folder in Google Drive. If your role is not in it, add it or ask Erica.

What loads at the start of each session

  • Who you are, so files are labeled to you
  • Active role JDs from the shared Role Launches folder
  • The latest calibration notes for each active role
  • Your sourcing strategy folder, including rubrics, shortlists, and batch history
  • Anyone in the talent dossier flagged as ready to contact who fits a current role
  • Whether HeadHunter is available

If something is not working

  1. Is the relevant connector active in Claude settings?
  2. Are you working from the CodePath workspace folder?
  3. Does the role have a folder in the Role Launches folder in Google Drive?

Tips

  • The rubric for the active role auto-loads, and the plugin tells you which one it is using.
  • Before any task that takes more than a minute, the plugin tells you what to expect.
  • After any /source-batch run you are offered a daily repeat at a time you choose.
  • The plugin writes without em dashes.
