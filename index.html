First-week checklist

Each item comes from the guides. Work through them in order.

  • Read Tools and Access and confirm you can sign in to Juicebox, Greenhouse, and LinkedIn Recruiter.
  • Set up Claude Cowork with the Starter Pack, then connect Google Drive, Notion, and Slack (Claude Setup).
  • Install the Sourcing Intelligence plugin and run /source-start to see the command list.
  • Check that the roles you own have a folder in the Role Launches folder in Google Drive.
  • Read the outreach standards and keep the pre-send checklist handy.
  • Name every new Juicebox project after its role, one project per role.
Tool change to know about. Gem is sunsetting in January 2027. Juicebox is the sourcing platform going forward.
